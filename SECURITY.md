# Security policy

This repository is a research artifact, not a vulnerability scanner or a
production cryptographic library. Do not submit real private keys, credentials,
or confidential target data to the runners.

For a suspected vulnerability in this repository, use the repository's private
GitHub security-advisory channel. Findings about Go, RustCrypto, or liboqs should
also follow the upstream project's disclosure policy. Experimental artifact
repetition alone is not evidence of a CVE.
